# 存入记录 Ego 浏览器验收记录

- 日期：2026-08-14
- 环境：本地 `http://localhost:5173/finance`，Ego task space `92`，已登录测试用户
- 证据级别：Ego 真实页面操作；不代表 Staging 或生产验收

## 操作记录

1. 通过 Finance 页面创建临时计划“Ego截图证据计划”，目标金额 ¥1,000.00，目标日期 2026-08-31；页面提示“存钱计划已创建”，卡片初始显示已存 ¥0.00。
2. 从该计划卡片点击“存一笔”，输入 ¥550.00，日期使用当天 2026-08-14，备注“Ego 截图证据首笔”；页面提示“存入记录已创建”。
3. 展开存入历史，卡片显示 55%、已存 ¥550.00、剩余 ¥450.00、1 条存入记录，历史行显示日期、金额、备注以及编辑/删除操作。
4. 打开存入记录删除确认后点击“取消”，原验收数据仍保持 ¥550.00 和 1 条记录；随后再次确认删除，页面提示“存入记录已删除”，卡片回到已存 ¥0.00、剩余 ¥1,000.00，并显示“还没有存入记录，存下第一笔吧”。
5. 打开计划删除确认，弹窗明确提示“计划中的全部存入记录也会被删除”；确认后页面提示“存钱计划已删除”，回到“还没有存钱计划”。
6. 最终页面刷新回读后未保留本次临时计划或存入记录；本次验收数据已通过页面操作清理。
