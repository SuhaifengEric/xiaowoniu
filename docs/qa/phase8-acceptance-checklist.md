## 键盘与辅助功能

- [x] Tab 可完成登录、注册和进入 Dashboard。
- [x] Dashboard 的模块导航和快捷入口可用 Enter/Space 操作。
- [x] 所有 icon-only 控件至少 44x44px，并有可读的 `aria-label`。
- [x] Dialog 打开后焦点进入内容，取消/关闭后焦点回到触发控件。
- [x] 非破坏性 dialog 可用 Escape 关闭；提交中不能误关闭。
- [x] 可用键盘完成创建、取消、删除确认、返回 Dashboard 和登出。
- [x] 加载状态使用 `role=status`/`aria-busy`，错误使用 `role=alert`。
- [x] 状态不只依赖颜色；金额、进度、倒计时和空值都有文字表达。
- [x] 在系统开启 reduced motion 后，页面没有必须依赖动画才能理解的状态。

## Dashboard 与数据一致性

- [x] 空用户看到四个模块的零值/空值，不把 `null` 误显示为预算为 0 或婚期为 0。
- [x] 有数据用户看到 Fitness、Learning、Finance、Wedding 的服务端摘要。
- [x] 当前考试倒计时、婚期倒计时和预算剩余使用服务端返回值。
- [x] 预算超支显示负数或等价的明确超支状态。
- [x] Dashboard 刷新失败时保留最后一次成功摘要，并显示可重试错误。
- [x] Dashboard 初次加载失败时显示可重试状态。
- [x] 从快捷入口进入对应模块并打开既有 dialog，刷新不会重复打开。
- [x] 非白名单 `action` 被忽略并从 URL 清除。
- [x] 用户 A 的摘要、详情和快捷操作不会泄露给用户 B。

## 记录结果

- 通过项：本机数据库 migration 状态、真实登录后的四模块核心录入与 Dashboard 回写、双用户隔离、删除确认/焦点恢复、390px/768px/1280px+ 响应式、错误重试、超支语义、快捷入口 query 清理与刷新、reduced motion。
- 失败项与复现步骤：无剩余本地验收阻塞。验收中发现 reduced motion 只作用于页面根节点、Dialog Portal 仍为 0.15s 动画；已将规则扩展到全局元素，并以 `prefers-reduced-motion: reduce` 的真实浏览器模拟复测为 0.01ms。
- 未执行项及原因：生产部署、生产密钥、备份恢复、目标环境 migration deploy 和回滚演练不在本地验收授权范围内。
