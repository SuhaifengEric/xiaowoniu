# 嫁嫁嫁婚姻进程专项测试用例（2026-08-14）

## 1. 测试目的与范围

本用例针对当前工作区最新的“嫁嫁嫁”婚姻进程改动，覆盖：

- 婚姻进程建档、幂等初始化和当前阶段复盘；
- 8 个婚姻节点的计划/事实分离、状态流转、补录和历史；
- 两次上门顺序、领证/婚礼顺序和订婚选择；
- 双方共识议题的记录、需再沟通、归档和文案边界；
- 阶段行动项与节点的关联，以及既有预算、花费、时间线执行能力回归；
- 390px、768px、1280px 三档浏览器布局和弹窗交互。

本轮只验证本地环境，不把自动化测试、Ego Browser 或本地 HTTP 结果表述为 Staging/生产验收。
