# 小窝牛页面级测试用例

## 1. 文档信息

| 项目 | 内容 |
| --- | --- |
| 文档用途 | 为 Web 页面验收、回归测试和发布前冒烟提供可执行的页面级用例 |
| 覆盖路由 | `/login`、`/register`、`/dashboard`、`/fitness`、`/learning`、`/finance`、`/wedding`、`/profile` |
| 页面角色 | 未登录访客、已登录用户 A、已登录用户 B |
| 真实浏览器 | 需要页面操作时使用 Ego Browser；自动化测试与真实浏览器结果分开记录 |
| 默认本地地址 | 前端 `http://localhost:5173`，后端 `http://localhost:3000` |
| 依据 | `frontend/src/routes`、`frontend/src/pages`、`frontend/src/components`、`shared/src`、`backend/API.md` 及现有 `docs/qa` 验收清单 |
| 当前状态 | 既有 205 条基线 + 嫁嫁嫁婚姻进程专项用例；每次真实执行仍需填写第 14 节记录 |

## 2. 使用规则

### 2.1 优先级

- **P0**：阻断登录、核心页面进入、核心新增/修改、数据串户或严重数据丢失。
- **P1**：核心页面可用但影响主要流程、错误恢复、删除确认、响应式或键盘操作。
- **P2**：边界文案、视觉细节、动画、长文本和低频异常。

### 2.2 证据类型

| 标记 | 含义 | 证据要求 |
| --- | --- | --- |
| `AUTO` | Vitest/Testing Library 等自动化页面测试 | 测试名称、通过日志、失败堆栈 |
| `EGO` | Ego Browser 本地或目标环境真实页面操作 | URL、关键页面截图、可见文案/状态、必要时控制台或网络错误摘要 |
| `HTTP` | 页面操作依赖的真实 HTTP/数据库状态 | 仅记录脱敏的状态码、业务结果和数据回读，不记录 Token、密码或连接串 |
| `STG` | Staging 真实地址验收 | 目标地址、构建 SHA、测试账号、迁移/备份前置证据 |
| `PROD` | 生产验收 | 仅在明确发布授权、观察窗口和回滚责任人确定后执行 |

页面级用例的定位优先使用可见语义：

- 按钮：`role=button` + 可见名称，例如“保存预算”“确认删除”。
- 输入：`label`，例如“预算金额”“当前密码”。
- 弹窗：`role=dialog` + 标题。
- 状态：`role=status`；错误：`role=alert`。
- 页面：`h1`、`nav` 的可见名称和 URL。

不要把 CSS class、React 组件内部状态或 API 单测结果单独当作页面通过证据。

### 2.3 通用测试账号和数据

测试环境使用合成数据，不在文档中记录真实密码。

| 数据 | 准备内容 |
| --- | --- |
| 用户 A-空数据 | 可登录，四个业务模块没有任何记录 |
| 用户 A-完整数据 | Fitness 有运动、体重、目标；Learning 有考试、科目、学习打卡；Finance 有预算、消费、存钱计划；Wedding 有预算、任务、花费 |
| 用户 B | 与用户 A 不同的账号，至少有一条可识别的记录，用于隔离测试 |
| 用户 C-边界数据 | Finance 预算为 `0`、发生超支；Wedding 有未来/今天/过去婚期、已取消任务、超预算花费；Learning 有长名称和已完成章节 |
| 长文本数据 | 50/51 字昵称、100/101 字考试/科目/计划名称、200/201 字任务名称、2000/2001 字备注；超过浏览器 `maxLength` 时仍需检查服务端错误展示 |

每条涉及写入的用例结束后清理临时数据，或使用独立测试账号；不使用生产数据做清理验证。

### 缺陷记录最低要求

1. 页面 URL、视口、账号标识和前置数据摘要；不记录密码、Token、Cookie 或完整请求体。

## 15. 发布前最小阻断集

以下用例任一失败，停止向下一环境提升：

- `COM-002`、`COM-003`、`COM-009`、`COM-022`：认证和受保护路由边界。
- `AUTH-002`、`AUTH-012`：登录、注册主流程。
- `DASH-003`、`DASH-010`、`DASH-012`：摘要、错误恢复、快捷入口。
- `FIT-011`、`FIT-019`、`LEA-018`、`LEA-024`、`FIN-008`、`FIN-014`、`WED-011`、`WED-025`、`PRO-003`、`PRO-012`：核心写入、删除和账号修改。
- `E2E-003`、`E2E-004`、`E2E-010`：跨用户隔离、登出清理和 Token 失效。
- `COM-018`、`COM-020`、`E2E-011`：响应式、reduced motion 和真实页面闭环。

本地自动化、真实本地浏览器、Staging 和生产均需独立填写执行记录。未完成目标环境的 Secret、数据库迁移、备份、回滚和授权确认时，只能标记为“未验证”，不能标记为发布通过。
